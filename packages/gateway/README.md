## Set up Environment Variables

Create a .env file with the following settings

```
PORT = 7070
NODE_ENV = development
LOG_LEVEL = 1
APP_NAME = OPENCRVS_API_GATEWAY
```

## Running the gateway

```
yarn start
```

to launch project with nodemon running.
